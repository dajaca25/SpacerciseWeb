# PDF slots

`design.html` embeds two PDFs from this folder by fixed filename:

| File | Shown as |
|------|----------|
| `style-exploration.pdf` | First embed — "Figma style exploration…" |
| `design-wireframe.pdf` | Second embed — "Figma design wireframe…" |

Drop the files in with exactly these names and push. Until a file exists, the
embed area shows a fallback with a link to the (missing) PDF.
